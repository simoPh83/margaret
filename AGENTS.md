## Node.js version

- Minimum: `>=22.20.0`, declared in `package.json` under `engines`.

## Markdown rules

Every Markdown file in this repo must pass the official markdownlint rule
set with the repo config in `.markdownlint.json`. Consult the rule
reference before writing or editing Markdown:
<https://github.com/DavidAnson/markdownlint/blob/main/doc/Rules.md>

`.markdownlint.json` disables only **MD013** (line length) — prose is not
hand-wrapped here. Every other rule is on at its default. Do not add
further exceptions to fix a file; fix the file.

Most violations come from these rules:

- **MD009** — no trailing whitespace.
- **MD012** — never two or more consecutive blank lines.
- **MD022** — blank line above and below every heading.
- **MD024** — no two headings with the same text in a file.
- **MD025** — exactly one top-level (`#`) heading per file.
- **MD031** — blank line above and below every fenced code block.
- **MD032** — blank line above and below every list.
- **MD034** — no bare URLs; use `<https://example.com>` or `[text](url)`.
- **MD040** — every fenced code block declares a language (`text` when
  there is no real one).
- **MD047** — file ends with exactly one newline.
- **MD060** — one table style per table. Use compact pipes throughout,
  delimiter row included: `| --- | --- |`, never `|---|---|`.
